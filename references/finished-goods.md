# Finished-goods BOM impact

1. Read the entire supplied `HPE_BOM.pdf` (29 pages in the supplied version, 46 component lines across 6 named end items); a retrieved excerpt is **not** proof of complete coverage. If only snippets are available and complete-BOM claims would be required, stop and ask for access to the complete PDF. The BOM has `Anaplan Code`, HPE part/SKU, `Base Qty`, `Max Qty`, BOM level, and model/system. Use base quantity for a base build; 0-base options are conditional on configuration. Maximum supported quantity is **not** base consumption. If a source has ambiguous parent/child edges (Synergy frame/blades), do not manufacture them.
2. Match material to BOM via exact Anaplan code, or a documented exact part/SKU crosswalk verified in model and PDF. Same code on different model lines may legitimately feed several finished goods. A similar name, family, or part without a crosswalk is not enough. List unmatched codes/materials as data issues; exclude from impact count. Record every matching finished good, BOM quantity and all simultaneous shortage materials. Do not imply generic accessories are BOM parts because names mention a product family.
3. For each finished good × location × period, if **usable unallocated inventory for every required component** and planned build quantity are available, compute `maximum buildable units = min_i floor(max(0, available_i) / required_qty_i)` over base components, and `units unbuildable = max(0, planned builds - maximum buildable units)`. Otherwise say “not determinable”; unmet material demand is neither available inventory nor FG units unbuildable. Identify a constraining component only when comparative component availability is established; otherwise call it a flagged matched component, not a proven bottleneck. For multiple finished goods sharing one component, warn capacity must be allocated and request priorities; do not count the same inventory independently for both.
4. Severity uses first **evidenced** risk week from shared gates; a forecast shortfall alone indicates potential FG build risk, not confirmed halted builds. Summarize unique affected end items by severity, table sorted Critical/High/Medium then first period, with FG, flagged/proven constraining material, location, first period, material shortfall, and unbuildable units or “not determinable.” Give a dated, quantified investigation action for each risk and list unmatched items, optional configurations and missing quantities/stock.
