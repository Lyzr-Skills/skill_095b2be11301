# Transfer source screening

1. Refresh the flagged material IDs and receiving site's first at-risk weeks as needed. Search the bound model for a forecast `Excess Available for Push and Pull (U)`-type measure; verify its semantics, native axes and scenario. Read **all other** stock-holding locations for each flagged material/week (page fully), not just a top sample; if coverage is incomplete, state it and don't assert “largest.” Where relevant to sustaining the transfer, check donor excess in the intervening weeks and recipient's continuing shortfall without adding the same carried-forward gap twice.
2. Rank candidates by largest **modeled excess at the required week** (not physical availability or fastest arrival). State donor, receiver, material ID/name, first shortage week, first-week material gap, forecast donor excess, proposed provisional transfer quantity = no more than verified uncovered need and donor's usable surplus when known. If donor stock is only forecast excess, label the suggested quantity conditional; do not claim it is released. If location/time labels are ambiguous, resolve before recommending.
3. For a truly “best” feasible source, request or verify reservations, local builds, cross-border constraints, transit lead time, earliest dispatch and arrival. Rank by earliest feasible arrival before excess when those facts exist; without them, call it a **largest-excess shortlist only**. For a shortfall already within the current week, an unverified transfer cannot be presented as on-time. No transfer is executed. Avoid inventing numeric logistics lead time.
