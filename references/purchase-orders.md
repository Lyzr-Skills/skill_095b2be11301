# Committed purchase-order pull-forward screening

1. Discover PO line / committed receipt modules and line item definitions in the bound model; verify location, scenario if applicable, material identifier, PO number + line, open remaining quantity, status/honoured/committed flag, expected receipt date and model-availability week. Do not infer commitment from a descriptive PO name. Prefer line-level data over a summary receipt total. Use read-only queries, page filtered lines completely and join material identity using an exact code or verified mapping.
2. Compare qualifying open committed lines due **after** each receiving site's first risk period with required material and provisional gap. If line is due on or before week but gap persists, diagnose allocation/timing rather than claiming pull-forward solves it. Show PO number/line, material, receiver, open quantity, promised date and model week, target arrival week, and attainable gap coverage capped at open amount (subject to confirmation). Multiple lines can be suggested without assuming split shipments or summing repeated weekly demand.
3. Cross-check real-world read date against every expected receipt date: a date in the past relative to the read date, even if the model calls it “open,” is **stale/unverified**. Clearly label historical model scenarios; don't describe a 2025 receipt as currently expedient in 2026. Verify original PO document against displayed material if labels conflict. Ask procurement for current unreceived quantity, vendor acceptance, revised date, and supplier lead time before concluding feasibility. If no qualifying lines, report “none identified in the verified filtered lines,” not “there are no POs.”
4. Rank potentially fastest resolution: already released transferable stock only if verified arrival timing; then executable PO expedite if supplier confirmation makes it timely; then new PO only if verified lead time fits. Where timing is not verified, rank **checks to make**, not claimed feasible outcomes. Each check names material, provisional needed quantity, destination location and required model week/date. Never say an order has been changed.
